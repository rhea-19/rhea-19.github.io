CASE 01 · FLAGSHIP

Hybrid Self-RAG
with External Knowledge Validation

Core problem. Self-reflection can improve a response without proving its claims are supported by evidence.

My approach. Turn hallucination mitigation into a staged verification problem instead of a single generation call.

01User query
→
02GPT-4 generation
→
03Self-reflection
→
04Claim extraction
→
05Wikipedia + ArXiv evidence
→
06Semantic FactScore
→
07Conditional FAISS fallback
DESIGN

Claim-level verification

Extracted atomic factual claims with dependency-based NLP parsing, then embedded each claim and retrieved evidence using Sentence-Transformers for semantic comparison.

CONTROL

Confidence gates compute

A FactScore threshold of 0.5 decides whether an answer is accepted or routed into dense retrieval and evidence-conditioned regeneration — keeping expensive fallback conditional.

RESILIENCE

Multi-source grounding

Live Wikipedia and ArXiv evidence is complemented by a locally indexed FAISS corpus, reducing dependence on a single external knowledge source.
